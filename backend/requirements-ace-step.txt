# ACE-Step 1.5 inference dependencies.

# We deliberately do NOT mechanically install every ACE-Step dependency:

# training stack are not needed to run inference from Umbra's backend.
#
#   pip install -r backend/requirements.txt -r backend/requirements-ace-step.txt
#
# ---------------------------------------------------------------------------
# PyTorch: install the right build for your machine FIRST, then this file.
#
#   CUDA 12.8   pip install torch torchaudio --index-url https://download.pytorch.org/whl/cu128
#   Apple       pip install torch torchaudio          # ships with MPS support
#   CPU only    pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
# ---------------------------------------------------------------------------
